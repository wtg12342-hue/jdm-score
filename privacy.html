1. 모으는 정보

JDM 악보 플레이어(이하 "앱")는 로그인 없이도 모든 기본 기능을 쓸 수 있습니다. 로그인하지 않으면 개인정보를 모으지 않습니다.

사용자가 원해서 "구글로 계속하기"로 로그인하면, 다른 기기에서도 이어서 쓸 수 있도록 아래 정보를 사용자의 계정에 저장합니다.

  • 계정 정보: 구글 계정의 이메일 주소, 이름, 계정 고유 번호(구글 로그인으로 받아요)
  • 곡 정보: 악보 파일 이름, 마디 수, 쪽 범위, 유튜브 영상 주소(ID)와 제목, 음원 파일 이름
  • 연습 정보: 맞춘 박자(템포·첫 박 위치·박 지도), 연주 순서, 시작 위치, 예비박·속도·반복 구간, 폴더 이름, 악보에 적은 표시·메모

2. 악보와 음원 파일

사용자가 연 악보(PDF·MusicXML)와 음원 파일은 사용자의 기기 안에서만 읽고 분석합니다. 로그인해도 파일 자체는 서버에 올리지 않습니다. 다른 기기에서는 같은 악보 파일을 열면 저장해 둔 박자·메모가 붙습니다.

3. 저장하는 곳과 기간

로그인한 경우 위 정보는 Google Firebase(Firestore, 서울 지역 서버)에 저장되며, 본인 계정으로만 읽고 쓸 수 있습니다. 계정을 삭제할 때까지 보관하고, 삭제하면 바로 지웁니다.

로그인하지 않은 경우 저장한 곡, 맞춘 박자, 화면 설정은 사용자의 기기(브라우저 저장공간)에만 저장됩니다. 앱을 지우거나 사이트 데이터를 지우면 함께 지워집니다.

4. 계정과 데이터 삭제

앱의 설정 → 내 계정 → 계정 삭제, 또는 웹의 계정 삭제 페이지에서 언제든 계정과 저장된 정보를 모두 지울 수 있습니다. 직접 지우기 어려우면 wtg12342@gmail.com으로 요청해 주세요. 로그아웃만 하면 기기에 있는 곡은 그대로 남습니다.

정보를 팔거나 다른 회사에 제공하지 않습니다. 로그인과 저장을 위해 Google(Firebase Authentication, Cloud Firestore)을 이용합니다. Firebase 개인정보 보호

6. 유튜브 사용

앱은 유튜브 영상을 재생하고 검색하기 위해 YouTube API 서비스를 사용합니다. 유튜브 기능을 쓰면 유튜브와 구글이 자체 정책에 따라 정보를 처리할 수 있습니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침

앱은 유튜브의 소리나 영상을 저장하거나 녹음하지 않습니다. 유튜브 데이터 접근 권한은 구글 보안 설정에서 언제든 해제할 수 있습니다.

7. 검색할 때 보내는 정보

유튜브 영상을 찾을 때 입력한 검색어는 검색 결과와 추천 검색어를 받기 위해 유튜브(구글)로 보내집니다. 곡 정보(템포 등)를 찾을 때는 영상 제목이나 악보 이름을 Deezer 음악 검색으로 보냅니다. 저희는 이 검색어를 따로 보관하지 않습니다. 앱 안에 남는 최근 검색어는 기기에만 저장됩니다.
